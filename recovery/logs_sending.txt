#CLIENT VS PG
The Client class in the node-postgres (pg) module represents a single, individual database connection that you manually open and close. 
You use Client specifically when:
You are writing a one-off script or migration tool that runs sequentially.
You need to manage transactions that require multiple queries to execute on the exact same connection.
You want full control over the connection lifecycle (opening, querying, and ending). 
In contrast, a Pool is used for web applications or high-traffic services to reuse connections efficiently, avoiding the performance cost of opening and closing new connections for every request.  While Client provides direct access to the underlying query interface, it is not designed for handling concurrent requests like a pool is.
